# Зависание Claude Code в Цикле Размышлений

**Проблема**: Claude Code зависает в режиме "размышления" (thinking) или выполняемая им команда выполняется бесконечно, делая CLI-интерфейс неотзывчивым.

Обычно это происходит, когда Claude запускает фоновый процесс, который не завершается самостоятельно, ожидает пользовательского ввода (который ИИ не может передать) или выполняет бесконечный цикл в скрипте.

---

## Симптомы

- CLI отображает спиннер или сообщение "thinking..." в течение нескольких минут без вывода текста или инструментов.
- Claude запустил команду типа `npm run dev` или локальный сервер разработки, заблокировав сессию.
- Тесты выполняются бесконечно из-за необработанных исключений или незакрытых соединений.

---

## Решение 1: Принудительная Остановка Выполнения

Если Claude Code завис или выполняет долгую команду, вы можете прервать процесс с клавиатуры, не закрывая сам терминал.

### Сочетание Клавиш

Нажмите **`Ctrl + C`** на клавиатуре.

- Однократное нажатие попытается безопасно прервать текущий инструмент или цикл размышлений и вернуть управление в интерфейс ввода.
- Если CLI по-прежнему не отвечает, нажмите **`Ctrl + C`** повторно или введите `/exit` (если строка ввода доступна).

---

## Решение 2: Избегайте Запуска Фоновых Серверов

Claude Code рассчитан на выполнение задач, которые завершаются самостоятельно. Если вы попросите его "запустить локальный сервер" или "выполнить docker-compose", он запустит команду и будет бесконечно ждать её завершения.

### Корректировка

Всегда запускайте долгоработающие серверы, компиляторы и вотчеры (watchers) в отдельном окне терминала, а не внутри сессии Claude Code.

Если необходимо проверить работоспособность сервера, укажите Claude запустить его с автоматическим тайм-аутом или принудительным завершением:

```
Запусти тесты, но убедись, что они запускаются с флагом --watch=false для выхода после завершения.
```

---

## Решение 3: Ограничение Автоматического Вызова Инструментов

Иногда Claude может попасть в цикл бесконечной компиляции: запускает сборку, видит ошибку, правит код, снова запускает сборку и так по кругу.

Чтобы разорвать этот цикл:

1. Прервите процесс с помощью **`Ctrl + C`**.
2. Дайте явную команду остановиться: "Прекрати сборку тестов. Давай сначала изучим файлы и составим план текстом перед следующей попыткой исправления".
