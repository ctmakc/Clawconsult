# Управление Окном Контекста в Claude Code

**Проблема**: При длительных сессиях или работе с большими файлами Claude Code может потреблять слишком много контекста. Это приводит к высокому расходу токенов, медленным ответам или ошибкам переполнения окна контекста (например, `Context window limit reached`).

Claude Code хранит всю историю диалога и контекст локальных файлов в рамках одного окна контекста. Управление тем, какие файлы считывает ИИ, критически важно для эффективной и экономичной работы.

---

## Симптомы Переполнения Контекста

- Claude начинает дольше отвечать на простые вопросы.
- Повторно сканируются большие структуры каталогов.
- Интерфейс выводит предупреждения о размере сессии или потреблении токенов.
- Предупреждения о лимитах запросов (rate limits) появляются слишком рано.

---

## Решение 1: Использование файлов `.claudeignore`

По умолчанию Claude Code сканирует файлы в вашем рабочем пространстве для понимания структуры проекта. Если проект содержит крупные артефакты сборки, папки зависимостей или дампы баз данных, Claude будет тратить токены окна контекста на их чтение.

### Действие

Создайте файл `.claudeignore` в корневом каталоге проекта:
```bash
touch .claudeignore
```

Добавьте шаблоны для исключения ненужных директорий:
```ignore
# Исключение каталогов зависимостей
node_modules/
vendor/
.venv/

# Исключение артефактов сборки
dist/
build/
.next/
out/
*.pyc

# Исключение настроек IDE и мета-файлов ОС
.idea/
.vscode/
.DS_Store

# Исключение больших датасетов и дампов БД
*.sql
*.sqlite
*.csv
*.json
```

## Решение 2: Сброс Истории Сессии

Если одна сессия терминала активна долгое время, история общения становится слишком большой. Вы можете очистить историю, чтобы сбросить окно контекста, не закрывая рабочую сессию.

### Команда

Внутри активной сессии Claude Code выполните слеш-команду для сжатия контекста:
```bash
/compact
```
Эта команда сгенерирует саммари текущих изменений и очистит старую историю диалога, мгновенно освободив окно контекста.

Также вы можете перезапустить сессию, введя команду `/exit` и затем запустив `claude` заново.

---

## Решение 3: Контроль Добавления Файлов

Избегайте использования масок (wildcards) или широких вопросов вроде "проанализируй весь проект". Вместо этого просите Claude прочитать конкретные файлы:

```
Проверь логику аутентификации в файле ./src/lib/auth.ts на наличие уязвимостей.
```

Если Claude запрашивает разрешение на чтение огромной директории, отклоните запрос и укажите путь к нужным файлам вручную.
