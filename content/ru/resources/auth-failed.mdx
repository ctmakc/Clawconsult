# Ошибка Аутентификации в Claude Code

**Проблема**: При запуске Claude Code возникает ошибка аутентификации (например, `Authentication failed`, `Invalid API Key` или `Unauthorized`), препятствующая началу работы сессии.

Claude Code подключается к сервисам Anthropic с помощью учетных данных OAuth или API-ключей. Конфликты переменных окружения, истекшие сессии авторизации или ограничения сети могут заблокировать доступ.

---

## Симптомы

- Запуск команды `claude` выводит: `Error: Authentication failed` или `401 Unauthorized`.
- CLI предлагает пройти аутентификацию в браузере, но перенаправление не срабатывает или код авторизации отклоняется.
- Ошибки биллинга, указывающие на валидность API-ключа, но при этом на балансе отсутствуют активные средства.

---

## Решение 1: Принудительное Обновление Сессии

Если вы авторизованы через OAuth, ваша сессия могла истечь. Вы можете выполнить принудительный выход и повторный вход для обновления токенов.

### Действие

Выполните команду выхода в терминале:
```bash
claude logout
```

Затем инициируйте вход заново:
```bash
claude login
```
Следуйте инструкциям на экране для авторизации CLI в браузере.

---

## Решение 2: Проверка Переменных Окружения для API-Ключа

Если ваша организация использует корпоративные API-ключи вместо OAuth, Claude Code проверяет переменную окружения `ANTHROPIC_API_KEY`.

### Действие

Убедитесь, что переменная установлена корректно:
```bash
echo $ANTHROPIC_API_KEY
```

If the output is empty or incorrect, set it in your current terminal session:
```bash
export ANTHROPIC_API_KEY="ваш-api-ключ"
```

Чтобы сохранить настройку навсегда, добавьте строку экспорта в конфигурационный файл вашего шелла (например, `~/.bashrc` или `~/.zshrc`):
```bash
echo 'export ANTHROPIC_API_KEY="ваш-api-ключ"' >> ~/.bashrc
source ~/.bashrc
```

---

## Решение 3: Исправление Прав Доступа к Хранилищу Токенов

В некоторых дистрибутивах Linux системный менеджер паролей не может безопасно сохранить токен авторизации, что приводит к повторным запросам входа.

### Действие

Очистите локальный кэш учетных данных вручную:
```bash
rm -rf ~/.claude/session.json
```
Перезапустите Claude Code и пройдите процедуру `claude login` заново.
