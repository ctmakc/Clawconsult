# Claude Code для Data Science

Дата-сайентисты тратят непропорционально большую часть времени на работу, не требующую их экспертизы: написание шаблонного EDA-кода, переформатирование датасетов, отладка конфликтов зависимостей, перевод аналитических намерений в рабочий SQL. Claude Code берёт эти накладные расходы на себя.

На этой странице рассматриваются практические способы, которыми дата-сайентисты используют Claude Code для ускорения реальной работы — не игрушечных примеров, а той беспорядочной, итерационной, дедлайн-ориентированной работы, которая заполняет большинство рабочих недель.

## Основные Сценарии Использования

### Автоматизация Разведочного Анализа Данных

EDA ценна, но утомительна. Claude Code может прочитать CSV или Parquet-файл, проинспектировать схему и создать полный EDA-ноутбук, охватывающий:

- Подсчёт пустых значений и стратегии импутации по каждому столбцу
- Графики распределения для числовых признаков (гистограмма + KDE)
- Подсчёт кардинальности для категориальных признаков
- Матрицу корреляций с аннотацией высококоррелированных пар
- Обнаружение выбросов методами IQR и Z-score
- Сводку дисбаланса классов для целевых переменных

Сгенерированный ноутбук включает ячейки с кодом и markdown с наблюдениями — готов к передаче, а не просто дамп кода.

**Шаблон промпта**:
```
Вот CSV-файл: [прикрепить или вставить схему].
Сгенерируй полный EDA-ноутбук. Выдели любые проблемы качества данных,
неожиданные распределения или признаки, которые вероятно потребуют 
трансформации перед моделированием.
```

### Генерация Кода для Ноутбуков

Когда вы знаете, какой анализ нужен, но не хотите писать шаблонный код, Claude Code напишет его. Примеры:

- «Сгенерируй sklearn-пайплайн со StandardScaler, SMOTE для дисбаланса классов и классификатором RandomForest с 5-кратной кросс-валидацией»
- «Напиши plotly-дашборд с выпадающими списками для выбора признаков и scatter-графиком, сравнивающим реальные и предсказанные значения»
- «Сгенерируй код для chi-square теста независимости для всех пар категориальных признаков и выведи значимые пары как DataFrame»

Claude Code также читает существующие ноутбуки, чтобы понять ваши соглашения, и генерирует новый код в том же стиле — используя вашу предпочтительную библиотеку визуализации, паттерны именования и формат документации.

### Отладка Пайплайнов Данных

Пайплайны данных падают предсказуемыми способами: несоответствие схем, неожиданные нулевые значения, принудительное приведение типов, проблемы памяти при больших джойнах, недетерминированный порядок сортировки. Claude Code помогает диагностировать их быстрее.

Вставьте traceback ошибки и соответствующий код пайплайна. Claude определяет:

- Строку, которая вызвала ошибку
- Почему это произошло (эволюция схемы, изменение данных выше по потоку, смена версии библиотеки)
- Исправление
- Защитную проверку, которую можно добавить, чтобы поймать ту же проблему раньше в следующий раз

Для DAG-ов Airflow и Prefect вставьте лог задачи, и Claude диагностирует сбой без необходимости понимать всю вашу настройку оркестрации.

**Шаблон промпта**:
```
Этот пайплайн падает со следующей ошибкой: [traceback].
Вот соответствующий код: [фрагмент].
Пайплайн запускается ежедневно против базы данных Postgres.
Диагностируй первопричину и предложи исправление и защитный предикат.
```

### Оптимизация SQL-Запросов

Claude Code — сильный партнёр по SQL. Типичные паттерны:

**Генерация запросов**: опишите бизнес-вопрос на обычном языке и получите корректный SQL-запрос. «Для каждого клиента, совершившего покупку за последние 90 дней, покажи дату первой покупки, общую сумму трат и наиболее распространённую категорию товара.» Claude пишет запрос, объясняет джойны и отмечает предположения о схеме.

**Оптимизация запросов**: вставьте медленный запрос и вывод EXPLAIN. Claude определяет отсутствующие индексы, ненужные полные сканы таблиц, неэффективные коррелированные подзапросы и паттерны N+1 в SQL, генерируемом ORM.

**Перевод запросов**: переводит между SQL-диалектами (PostgreSQL → BigQuery, MySQL → Snowflake) с правильными заменами имён функций, арифметикой дат и синтаксическими различиями оконных функций.

**Дизайн схемы**: опишите сущности и отношения в вашей модели данных. Claude генерирует нормализованную схему с соответствующими индексами, ограничениями и комментариями.

С [MCP-сервером базы данных](/services/mcp-integration) Claude может читать вашу реальную схему во время сессии — больше не нужно вставлять определения таблиц. Он генерирует запросы, откалиброванные под ваши реальные имена столбцов, типы данных и существующие индексы.

### Помощь в Feature Engineering

Claude Code помогает переводить доменную интуицию в код признаков:

- «Создай лаговые признаки для столбца sales_amount на интервалах 7, 14 и 28 дней, по customer_id»
- «Закодируй этот столбец с датами в циклические признаки, используя трансформацию синус/косинус»
- «Извлеки домен email из столбца email и создай бинарный флаг для бизнес- vs. личных доменов»

Для NLP-признаков: очистка текста, TF-IDF векторизация, генерация эмбеддингов, настройка извлечения сущностей.

## Пример Рабочего Процесса: Анализ Оттока Клиентов

**Ситуация**: Дата-сайентисту нужно построить модель предсказания оттока для SaaS-продукта. Данные в Postgres.

**Сессия с Claude Code + MCP базы данных**:

1. «Проинспектируй таблицы users, subscriptions и events и опиши данные, доступные для предсказания оттока.» — Claude читает реальную схему и суммирует.
2. «Напиши SQL-запрос для создания матрицы признаков: одна строка на пользователя, с метриками использования за последние 30, 60 и 90 дней, тарифным уровнем и меткой оттока.» — Claude генерирует запрос с реальными именами столбцов.
3. «Сгенерируй EDA-ноутбук для этой матрицы признаков.» — Claude пишет ноутбук.
4. «Создай sklearn-пайплайн с предобработкой признаков, подходящей для каждого типа столбца, и классификатором gradient boosting. Включи расчёт значений SHAP.» — Claude пишет код моделирования.

Результат: рабочий baseline-модели оттока за один день, с документацией, вместо двух дней написания шаблонного кода.

## Шаблоны Промптов для Data Science

**Для EDA:**
> «Проанализируй [датасет/схему]. Сгенерируй полный EDA, охватывающий распределения, пропущенные значения, выбросы и заметные паттерны. Отметь всё, что повлияет на моделирование.»

**Для отладки:**
> «Этот пайплайн падает с [ошибкой]. Код: [фрагмент]. Диагностируй и исправь.»

**Для SQL:**
> «Сгенерируй SQL-запрос для [бизнес-вопрос]. Схема: [таблицы и столбцы]. Оптимизируй для [Postgres/BigQuery/Snowflake].»

**Для моделирования:**
> «Создай пайплайн [тип модели] для [целевой переменной]. Признаки — [список]. Включи [кросс-валидацию / важность признаков / метрики оценки].»

## Начало Работы

Claude Code хорошо работает с Jupyter (через терминал), ноутбуками VS Code и рабочими процессами на основе чистых скриптов. Для команд, где данные живут в базе данных, [интеграция MCP с базой данных](/services/mcp-integration) даёт наибольший прирост производительности — Claude читает вашу реальную схему и образцы данных вместо работы по описаниям.

Для помощи с настройкой, специфичной для data science сред (conda, virtualenv, JupyterHub или облачные ноутбуки), смотрите наш [сервис настройки Claude Code](/services/claude-code-setup).
